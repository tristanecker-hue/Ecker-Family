Überfällige Aufgaben
Wer eine offene Aufgabe hat, deren Termin vorbei ist, bekommt jeden Tag eine Erinnerung per Push, bis sie erledigt ist.
Pad-Modus (Wand-iPad)
Der Benutzer «Pad» zeigt auf einem iPad an der Wand Uhr, Termine, Essen und alle offenen Aufgaben – nur anzeigen, nichts änderbar. In der Testphase erscheint die Anmeldung «Pad» nur, wo du sie hier einschaltest.

Von Familienmitgliedern wird das Profilbild gezeigt. Für alle anderen (z. B. Oma) kannst du ein Foto hinzufügen.
🌙 Nachtmodus
Nachts wird das Pad abgedunkelt. Antippen macht es eine Minute hell.
🗑️ Abfuhrtermine
